# Requirements

## Parse Requirements
REQ-1: The parser shall extract a requirement id and description from correctly formatted requirements.

REQ-2: The parser shall return an issue for each improperly formatted requirement file.

REQ-3: The parser shall return an issue for each incorrectly formatted requirement.

REQ-4: The parser shall be able to support a requirement spanning multiple lines without separating blank lines.

REQ-5: The parser shall not return an issue if the file and all requirements are correctly formatted.
